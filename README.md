# PromptTest AI Mobile QA Simulation

This Python script simulates PromptTest's core concept: generating mobile QA automation from natural language descriptions. It mimics an AI interpreting a test scenario to control a simulated mobile app.

## Language

`python`

## How to Run

Run this script using Python: `python prompttest_sim.py`
